# MLOps Lab

Учебный MLOps-проект: сервис классификации инцидентов.

## Цель
Пройти полный путь модели от обучения до развёртывания и мониторинга.

## Планируемый стек
- Python, scikit-learn, FastAPI
- MLflow, PostgreSQL, MinIO
- Docker, Kubernetes, Helm, Argo CD
- Prometheus, Grafana
- GitHub Actions
